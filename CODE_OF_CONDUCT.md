# Code of Conduct

## Purpose

Busiq is maintained as a professional project. Participation in issues, pull requests, discussions, and related communication must remain respectful, focused, and constructive.

## Expected Behavior

- Use clear, professional, and respectful language.
- Keep feedback specific to the project and its technical or design goals.
- Respect maintainers, contributors, users, and third-party rights.
- Report problems with enough context for maintainers to evaluate them.
- Follow the proprietary license and do not reuse project code without written permission.

## Unacceptable Behavior

- Harassment, threats, insults, discrimination, or personal attacks.
- Spam, disruptive comments, or repeated off-topic posting.
- Publishing private information without permission.
- Attempting to bypass the project license or encouraging unauthorized use.
- Submitting malicious code, deceptive changes, or security-abusive material.

## Enforcement

Maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate this Code of Conduct. Maintainers may also restrict participation when behavior creates risk for the project or its community.

## Reporting

Report conduct concerns through the repository security contact or by contacting the repository owner directly through GitHub.
