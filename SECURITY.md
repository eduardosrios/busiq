# Security Policy

## Supported Versions

Busiq is in early repository setup. No public production version has been released yet.

Security review applies to the current default branch and any published release after template implementation begins.

## Reporting a Vulnerability

Do not open public issues for security vulnerabilities.

Report security concerns privately to the repository owner through GitHub. Include:

- A clear description of the issue.
- Steps to reproduce it.
- Affected files, pages, or assets.
- Potential impact.
- Any safe proof of concept, if available.

## Response Expectations

Maintainers will review valid reports, prioritize fixes based on impact, and publish updates when appropriate.

## Scope

Security reports may include:

- Cross-site scripting risks in HTML or JavaScript.
- Unsafe third-party scripts or assets.
- Exposed secrets or credentials.
- Broken access assumptions in deployment configuration.
- Supply-chain or dependency risks if tooling is introduced later.

Reports about unrelated infrastructure, social engineering, denial-of-service testing, or automated scanner noise without demonstrated impact may be closed without action.
