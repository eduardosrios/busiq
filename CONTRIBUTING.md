## Contribution Policy

External contributions are reviewed at the maintainers' discretion. Before submitting substantial changes, open an issue or contact the repository owner to confirm the work is wanted.

## Project Type

Busiq is a static HTML, CSS, and JavaScript website template. Do not introduce React, build frameworks, or package managers unless the maintainers explicitly request them.

## Development Guidelines

- Write all project files, documentation, comments, commit messages, and user-facing text in English.
- Keep implementation focused on the corporate business website template scope.
- Commit only project-related website files, assets, and repository governance files.
- Do not commit local agent instructions, scratch files, generated logs, temporary files, dependency folders, or unrelated documentation.
- Use accessible, responsive, semantic HTML.
- Keep CSS and JavaScript organized, readable, and framework-free unless instructed otherwise.
- Optimize images and assets before adding them to the repository.

## Pull Requests

Pull requests should include:

- A clear summary of the change.
- A concise description of visual changes when relevant.
- Notes about browser testing when applicable.
- Confirmation that no unlicensed third-party material was added.
